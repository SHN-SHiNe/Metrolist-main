# SHiNe MUSIC

Android 音乐播放器

---

### 关于本项目

本项目基于 [Metrolist](https://github.com/MetrolistGroup/Metrolist) 的 UI 框架深度修改而来。

原 Metrolist 是 YouTube Music 客户端，本项目的所有后端功能已完全重写，与 YouTube Music 无任何关联。仅继承并改造了其 Material 3 UI 界面。
